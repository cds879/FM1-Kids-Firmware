FM1 Kids

A simple firmware for the M-VAVE FM-1, made for young children. Version @KID_VERSION@.

Install

  1. Use Chrome or Edge on a computer. Charge the FM-1.
  2. Connect the FM-1 with a USB-C data cable and switch it on.
  3. Press Install FM1 Kids. On the page that opens, choose Connect device, then Device update, and install. Allow MIDI access when Chrome asks.
  4. Keep the FM-1 connected and switched on until the page says it is done.

Install FM1 Kids

First time on this FM-1?

Back up the FM-1 first, and consider installing the original FM1 Open interface built by this project once, to check everything works, before FM1 Kids. The flashing guide explains both, and how to build the recovery dongle.

Original FM1 Open interface (hardware test)

Going back

Each install page also carries M-VAVE's stock V15 firmware: use its stock restore under Device update. Other FM-1 firmware installs over FM1 Kids with its own installer as usual.
