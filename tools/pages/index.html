FM1 Kids

A simple firmware for the M-VAVE FM-1, made for young children. Version @KID_VERSION@.

Install

  1. Use Chrome or Edge on a computer. Charge the FM-1, switch it on, and connect it straight to the computer with a USB-C data cable. Close other MIDI apps.
  2. Press Install FM1 Kids. The page opens on Device update: press Connect device and allow MIDI devices when Chrome asks.
  3. Coming from other firmware (stock V15, FM1 Open, ...), the page says so: press Enable force flash and reconnect. This is expected.
  4. Tick the backup box, press Force flash (or Start update) and confirm.
  5. Keep the FM-1 connected and switched on until the page says it is done. Don't use Restore original V15: that installs M-VAVE's original firmware.

Install FM1 Kids

Won't connect? Switch the FM-1 off and on, replug the cable, and close other tabs or apps using MIDI (only one can talk to the FM-1). The install page has more tips.

First time on this FM-1?

Back up the FM-1 first, and consider installing the original FM1 Open interface built by this project once, to check everything works, before FM1 Kids. The flashing guide explains both, and how to build the recovery dongle.

Original FM1 Open interface (hardware test)

Going back

Each install page also carries M-VAVE's stock V15 firmware: under Device update, open Recovery & force update and choose Restore original V15. Other FM-1 firmware installs over FM1 Kids with its own installer as usual.
